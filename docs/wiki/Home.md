# Module Funding pour Dolibarr ERP CRM

> Documentation du module **Funding** développé par [BB2A](https://www.bb2a.fr) pour [Dolibarr ERP CRM](https://www.dolibarr.org).

Le module **Funding** permet de gérer les **dossiers de financement** (propositions financières, leasing/location avec option d'achat, retenue de garantie) associés aux propositions commerciales, commandes et factures Dolibarr.
